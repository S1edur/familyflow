# Family Flow

Сімейний застосунок на двох: задачі в стилі Linear, місячний бюджет із чеклістом
платежів, фонди на нерегулярне, борги, спільний список покупок.

## Запустити

```bash
npm install      # один раз
npm run dev      # http://localhost:5173
```

`npm run dev` піднімається з `--host`, тож із телефона в тій самій Wi-Fi
відкривається за адресою, яку виведе Vite (`Network: http://192.168.x.x:5173`).

## Зібрати

```bash
npm run build && node build-single.mjs
```

- `dist/` — звичайна збірка під хостинг
- `dist/family-flow.html` — усе в одному файлі, відкривається подвійним кліком
- `dist/artifact.html` — те саме без каркаса, для публікації як артефакт

## Де що лежить

```
src/data/types.ts    типи — дзеркалять майбутню схему Postgres
src/data/seed.ts     стартові дані
src/data/store.ts    уся логіка: генерація платежів і задач, похідні значення, дії
src/lib/money.ts     гроші в копійках, форматування, курс
src/lib/dates.ts     дати українською, повторення, «через 3 дн.»
src/components/      примітиви інтерфейсу
src/pages/           екрани
```

## Стан даних

Поки що все живе у `localStorage` (ключ `familyflow.v1`). Це навмисно: спершу
доводимо функціональність, потім підключаємо Supabase. Коли підключимо —
змінюється тільки `src/data/store.ts`, решта коду лишається як є.

Скинути дані до стартових: у консолі браузера
```js
localStorage.removeItem('familyflow.v1'); location.reload()
```

## Що вже працює

- Задачі: статуси, 5 рівнів пріоритету (без пріоритету сортується останнім),
  виконавець у два кліки, дедлайн, «відкласти до», підзадачі, баланс за 28 днів
- Повторювані побутові задачі: «кожні N днів після виконання» — рівно один
  відкритий екземпляр, прострочення не накопичуються
- Місяць: план проти факту по конвертах, чекліст платежів у один тап,
  «інша сума» для змінних (комуналка сама вчиться на медіані останніх шести)
- Швидкий запис витрати з цифрової клавіатури, шаблони з історії, UAH/USD/EUR
- Фонди: скільки треба цього місяця = (ціль − баланс) / місяців до дати
- Борги: залишок, прогрес, прогнозна дата закриття
- Покупки: спільний список, групування за відділами, «завершити похід» — одна
  сума з чека стає однією витратою

## Чого свідомо ще немає

Аналітика, спільний простір для фото, налаштування конвертів і шаблонів,
закриття місяця майстром, авторизація. Це наступні кроки.
